# Unity WebGL build goes here

This directory is intentionally empty until a real Unity WebGL build is exported.

After building with Unity's Web platform, copy the generated files into this directory. Preserve the filenames and folder layout generated by Unity. Typical output includes:
- index.html (Unity template output; merge its loader logic into the repository root page or configure a separate route)
- Build/*.loader.js
- Build/*.framework.js
- Build/*.wasm
- Build/*.data

Do not add a fake or hand-written .wasm/.data file. Vercel cannot compile Unity source code. Test the build locally in a browser before deploying.

For large .data files, verify GitHub's file limits and Vercel deployment limits; use Git LFS or external object storage if necessary.
